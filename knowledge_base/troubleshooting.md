# Troubleshooting

## The app shows an error when saving
Refresh the page and try again. If it still fails, clear the browser cache or try a private window. If the error has a code (for example E-502), send us the code and the time it happened.

## The dashboard is slow
Large date ranges can take up to 30 seconds. Try a shorter range or turn off the "compare to previous period" option.

## Status page
If several things fail at once, check our status page for any ongoing incident before trying anything else.
